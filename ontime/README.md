# ONTIME 作息紀錄（時刻表）

記錄出門、通勤、上班、用餐和睡眠。夜班跨過午夜時，仍然知道這是哪一個工作日，同時看得到事件的真實日期。

## 怎樣開啟

這是不需要建置的靜態網頁 App（HTML、CSS、JavaScript 模組），放在任何靜態網站伺服器即可：

```bash
cd ontime
npx serve .          # 或 python3 -m http.server
```

用手機瀏覽器開啟後，選「加到主畫面」就可以像 App 一樣使用。首次開啟後可以離線記錄。

開發時可以在網址加上：

- `?now=2026-10-13T03:18`：固定「現在」的時間，方便看夜班情境。
- `?nosw`：不註冊 Service Worker，避免快取舊檔案。

第一次使用可到「我的 › 安裝與示範」進入獨立示範模式。按頂部「返回我的紀錄」回到個人資料。

### 2.43 面板統一

所有面板（補登、整趟、瞓醒喇、食咗飯、休息、補睡眠）用同一套樣式：揀咗係淡藍底加藍邊，有類別嘅選項用類別色，步驟編號變淡，確認框改中性淡藍；整趟面板預填嘅時間用藍字。計算規則冇改。

### 2.37 精修

參考 impeccable 同 UI UX Pro Max：一撳就記三粒掣用類別色、需要補的紀錄講實際過咗幾耐、桌面深藍側欄、用餐頁頂用餐色、時間線核對圈搬去右邊、設定備份改成清單、新增面板其他補記方式變正式選項、選字／捲軸／焦點框跟主色。計算規則冇改。

### 2.35 全日時間帶

首頁最頂係今日 24 小時嘅時間帶：睡眠、通勤、上班、食飯按時間排喺一條色條上，夜班跨過午夜一眼睇到，「而家」指針標住現在位置。下面就係現在狀態同主掣。時間帶同頁頂底色跟時段（夜晚、清晨、日間、黃昏）轉色，唔會閃。街景插畫改為喺「我的 › 外觀」開關。

### 2.34 夜班記錄與備份

在「我的 › 漏記提醒」設定睡眠、到家、用餐及收入提醒。收入提醒列出最近 48 小時內收工而未填收入的按單班次，並顯示各班的工作日。匯出行事曆後，在手機行事曆開啟 `.ics` 並接受提醒。調整班表或睡眠計畫後請重新匯出。

在「一週與班表」點一班可改時間或工作，按「複製上一週的班表」可先核對將加入的班次。按單工作的整趟面板和統計明細可以直接填收入及單數。

「我的 › 資料與備份」可匯出並還原完整 JSON 或完整 CSV。工時報表 CSV 用來看工時與收入。清除或取代前的安全備份可以在同一頁下載。從臨時版搬資料時，先在臨時版備份頁匯出 JSON，再到 OnTime 按「從臨時版匯入」，貼上、核對每趟的工作日與實際時間，再確認。匯入後可按提示的「復原」。

## 頁面

| 頁面 | 手機 | 桌面 |
| --- | --- | --- |
| 今天 | 頂部狀態句、可展開的街景、現在狀態、跟場合變的主按鈕、三粒「一撳就記」（食咗飯、瞓醒喇、去瞓）、需要補的紀錄、下一件事；詳細收起 | 另加四行時間軸、紀錄表與檢視面板（可直接改時間） |
| 時間線 | 工作日／日曆日切換、本週日期列 | 同時顯示分行時間軸 |
| 一週與班表 | 由「時間線」右上角進入 | 一週時間軸、範本、最下面的大月曆（可多選日期批次排班） |
| 睡眠 | 計時圓環、我瞓醒喇、補記、所屬工作日、近七天、計畫 | 兩欄排版 |
| 用餐 | 一撳記低現在、安排／確認、相片 | 兩欄排版 |
| 統計 | 工時、計薪、按單實收、CSV 匯出 | 五個重點數字與出勤明細 |
| 我的 | 個人設定、工作設定、JSON／完整 CSV 備份、臨時版匯入、行事曆提醒、獨立示範 | 同左 |

快捷鍵（桌面）：`N` 開啟補登，`Esc` 關閉面板。

## 程式結構

```
ontime/
  index.html            入口
  css/app.css           時刻表設計、手機與桌面排版、場景動畫
  js/time.js            日期與時間工具（當地時間、夏令時間）
  js/logic.js           作息規則：工作日、睡眠歸屬、睡前預算、日曆日分配、收入（純函式）
  js/store.js           本機 IndexedDB 儲存
  js/sync.js            Google 登入與 Firestore 雲端同步
  js/actions.js         使用者動作、匯入匯出、示範資料
  js/app.js             頁面切換、按鈕與表單處理
  js/views/*.js         各頁畫面；hero.js 是頂部狀態句、可展開的街景
  sw.js                 Service Worker（快取 App 外殼與字體）
  tests/logic.test.mjs  作息規則測試
  tests/quick-log.test.mjs  一撳就記的跨夜測試（午夜前後瞓、凌晨食飯、連續兩晚夜班、夏令時間）
  tests/trip.test.mjs  整趟一次過填的測試（七格時間跨午夜、只改一格、連續兩晚夜班、擋住不合理時間）
  tests/hero-gallery.html  所有場景狀態的預覽頁（加 ?compact 看手機版）
```

## 測試

```bash
cd ontime
npm test
```

測試使用 `America/Toronto` 時區，包含夜班跨午夜、下班後睡眠歸屬、睡前未安排時間、夏令時間結束當天、按單收入等情境。

## 發佈新版本

每次發版，把 `sw.js` 的 `VERSION` 升到新的版本號，並更新 `tests/r9-sw-cache-cleanup.test.mjs` 的版本號和舊快取清單，使用者下次開啟時會看到「有新版本」提示。

## 目前的限制

- 雲端同步：到「我的 › 雲端同步」用 Google 登入。資料存在 Firebase 專案 `dicky-quota-tracker-2026` 的 `users/{uid}/apps/ontime`，相片另存為 `ontime-photo-{餐次 id}`。同步按每筆紀錄的修改時間逐筆合併；兩部裝置同時改同一筆紀錄時，以較晚修改的為準。
- App 部署的網址要加入 Firebase Authentication 的「授權網域」，Firestore 規則要允許登入者讀寫自己 `users/{uid}` 底下的文件，否則登入或同步會失敗。
- 匯入可以讀新版的 JSON 備份，也可以讀舊版 ONTIME 的備份（`dicky-ontime-backup`）。
- 設計思路、需求與每一頁的說明見 [DESIGN.md](DESIGN.md)。
